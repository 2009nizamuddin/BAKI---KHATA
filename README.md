# বাকির খাতা 📒

দোকানে দোকানে বাকি নেওয়া জিনিসের হিসাব রাখার একটি সহজ, সুন্দর ওয়েবসাইট।
কোনো সার্ভার বা ডেটাবেজ লাগে না — সব হিসাব আপনার নিজের ব্রাউজারে সেভ থাকে।

## ফিচার
- একাধিক দোকান যোগ করা
- প্রতিদিনের "বাকি নিলাম" ও "টাকা দিলাম" এন্ট্রি
- প্রতিটি দোকানের বাকি অটোমেটিক হিসাব
- সব দোকান মিলিয়ে মোট বাকির সামারি
- এক ক্লিকে JSON ব্যাকআপ ডাউনলোড
- মোবাইল-ফ্রেন্ডলি, বাংলা ইন্টারফেস

## GitHub Pages-এ পাবলিশ করার নিয়ম

1. GitHub-এ একটি নতুন রিপোজিটরি বানান (যেমন: `baki-khata`)।
2. এই ফোল্ডারের সবগুলো ফাইল (`index.html`, `css/`, `js/`) সেই রিপোজিটরিতে আপলোড করুন।
   - সরাসরি GitHub ওয়েবসাইট থেকে "Add file → Upload files" দিয়ে করা যাবে।
   - অথবা `git` দিয়ে:
     ```bash
     git init
     git add .
     git commit -m "প্রথম কমিট: বাকির খাতা"
     git branch -M main
     git remote add origin https://github.com/আপনার-ইউজারনেম/baki-khata.git
     git push -u origin main
     ```
3. রিপোজিটরির **Settings → Pages**-এ যান।
4. **Source**-এ `main` ব্রাঞ্চ এবং `/ (root)` ফোল্ডার সিলেক্ট করে **Save** চাপুন।
5. কিছুক্ষণ পর একটি লিংক পাবেন, যেমন:
   `https://আপনার-ইউজারনেম.github.io/baki-khata/`
   এই লিংকেই আপনার সাইট লাইভ হয়ে যাবে।

## ডেটা কোথায় থাকে?

সব দোকান ও এন্ট্রি আপনার ব্রাউজারের `localStorage`-এ সেভ হয় — অর্থাৎ যে ফোনে/কম্পিউটারে
এবং যে ব্রাউজারে সাইটটি খুলবেন, ডেটা সেখানেই থাকবে। তাই:
- ব্রাউজারের ডেটা/ক্যাশ মুছে ফেললে হিসাব হারিয়ে যেতে পারে।
- মাঝে মাঝে ওপরের ⇩ বাটনে চেপে ব্যাকআপ (JSON ফাইল) ডাউনলোড করে রাখা ভালো।
- একই ডেটা অন্য ডিভাইসে দেখতে হলে আপাতত সেই ডিভাইসেও আলাদাভাবে এন্ট্রি করতে হবে
  (ভবিষ্যতে চাইলে ক্লাউড সিঙ্ক যোগ করা যাবে)।
